# Optional instruction supplements

Add focused guidance that belongs to this instance. No company policy, package
source, service routing, or personal preference is supplied by the scaffold.

Supplements do not activate themselves, grant authorization, or establish a
universal instruction hierarchy. Check the actual client's supported loading
and precedence. Merge selected sections without replacing unrelated guidance;
record the owned sections locally. Keep environment-specific rules explicitly
scoped and do not export machine diagnostics or private bindings.
